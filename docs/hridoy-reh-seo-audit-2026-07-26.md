## 三、按 19 个方法逐项评级

评级含义：**已就绪** / **可小测** / **阻塞** / **不适用（勿照搬）**。

### 方法 1：GSC 查询缺口优化 — **阻塞（样本不足）**

- 现状：唯一可评分行是品牌词 → 首页，37 次展示、0 点击，属 `low-sample`。
- 判断：方法论要求“高曝光且正文未覆盖”才改页；当前几乎没有可审计的非品牌查询行，**不能**把 AI 聚类当成批量改写指令。
- 动作：先把 GSC API/人工导出打通，攒满至少 28 天、单页/单查询 ≥50 impressions 后再跑缺口 SOP。在此之前只维护现有页面事实准确性。

### 方法 2：内容刷新优先于盲目扩量 — **已就绪（方向正确，缺下滑信号）**

- 现状：产品落地页、资源指南、比较页已存在；站点近期以证据对齐与 FAQ schema 为主，而非盲目扩量，符合方法 2。
- 缺口：无“点击下降最大页面”时间序列，无法按点击差异排序。
- 动作：建立 30/60/90 天页面级复盘表（点击/曝光/CTR/位置/询盘）；优先刷新已有高意图页（OEM、wholesale、buffing、flap disc RFQ 指南），不新建关键词变体页。

### 方法 3：高购买意图比较页 — **可小测（骨架有，深度不足）**

- 现状：`/compare/oem-vs-off-the-shelf-abrasive-kits` 含 MOQ、品牌、验证、补货、单价维度与 FAQ；`/alternatives/...` 含五种采购模式。
- 缺口：无具体价格/总成本数字（B2B 可接受为“询价确认”）、**正文未突出更新时间**（仅 schema `dateModified`）、无一手测试或客户证据、**无中文版**。
- 动作：给比较页增加可见“Reviewed YYYY-MM-DD”、风险/替代项结论条件、回链到 `/oem-private-label`、`/sample-kit`、`/procurement-terms`；证据批准后再补真实测试段落。

### 方法 4：记者关键词与统计资产 — **阻塞（资产缺失）**

- 现状：站内无行业规模、份额、增长率类可追溯统计页；`case-studies` 偏薄（EN ~576 词，ZH ~235 词）。
- 动作：在证据批准前**不编造**市场规模；可先建“公开口径与引用规范”页（已有 evidence-center / llms.txt 方向），把可核验的 MOQ、交期、包装、合规边界做成表格资产。

### 方法 5：图片作为搜索资产 — **可小测（基础好，有两处体积问题）**

- 现状：多数 WebP、描述性文件名、有 ALT；`next.config` 支持 AVIF/WebP。
- 问题：`oem-abrasive-packaging-concept-v2.jpg` ~437KB、`qc-evidence-planning-concept-v2.jpg` ~367KB 未压成 WebP；首页 hero 用原生 `<img>`，不经 `next/image` 优化管线。
- 动作：两张 JPG 转 WebP/AVIF 并保留描述性文件名；统一关键视觉走 `next/image`；不要为 SEO 往 ALT 堆关键词。

### 方法 6：编辑型外链而非制造链接 — **已就绪（候选库正确，勿批量提交）**

- 现状：`docs/seo/backlink-prospects.csv` 已按官方核验与评分管理；展会入口优先于目录垃圾链。
- 边界：不买链、不强制嵌入 dofollow、不以 DR 为目标；需人工授权后再提交展会/协会。

### 方法 7：社交 SERP 实验 — **不适用（现阶段）**

- 判断：磨料 OEM/批发查询的 SERP 通常不是 X/LinkedIn 主导；且本站几乎无自然点击基线。
- 动作：仅当目标词 SERP 已出现社交结果时再小测；不把 Medium 转载当增长证据（若转载必须 canonical 回原站）。

### 方法 8：AI 是分析与执行放大器 — **已就绪**

- 现状：项目已有 GSC/证据/转化/权威/竞争 skills 与确定性脚本；AI 适合聚类与草稿，人工负责意图、事实与发布。
- 边界：不把“用 AI 替代 SEO 团队”当执行目标。

### 方法 9：渠道必须匹配产品与受众 — **已就绪（需收窄）**

- 匹配渠道：五金/磨料展会、工业供应商目录（经核验）、采购资源页、买家社区中的真实贡献。
- 不匹配：Product Hunt / 泛 SaaS 发布节奏不宜作为主渠道。
- 动作：只保留 1–3 个高匹配渠道（建议：CIHS / Eisenwarenmesse 资料准备、Thomasnet 研究），各自定义内容格式与转化指标。

### 方法 10：发布前建设分发能力 — **部分适用**

- 站点已上线；更贴切的是“展会/目录提交前准备证据包”，而非 PH 星期二技巧。

### 方法 11：免费工具当成分发产品 — **可小测（中长期）**

- 现状：无计算器/选型工具。
- 机会：磨料 grit 选型、OEM kit BOM 清单生成、RFQ 字段校验器——有真实使用价值后再谈嵌入；嵌入链接默认 nofollow/可选署名。
- 优先级低于证据与 GSC 样本积累。

### 方法 12：寄生 SEO — **不适用（勿执行）**

- 不建 Google Sites 低价值寄生页，不批量 doorway。

### 方法 13：国际 SEO — **可小测（主链路好，决策页缺口）**

- 现状：双语 URL 稳定；`createPageMetadata` 生成 en / zh-CN / x-default（x-default→英文）；canonical 指向同语言版本；sitemap 对 localizedRoutes 输出 alternates。
- 缺口：`/compare/*`、`/alternatives/*`、`/solutions/*` **无中文镜像、无 hreflang**；语言切换可能回退首页。
- 动作：先为这 3 条决策页补完整中文版 + hreflang 互标，再用 Screaming Frog/自建 crawl 查断裂互返；不要一次铺开新语言市场（`market-candidates.csv` 显示美国亦仅 observation）。

### 方法 14：先修产品与留存，再用 SEO 放大 — **阻塞（转化可测性）**

- 现状：公开路径 contact / sample-kit 结构完整，RFQ 脚本无结构错误；UTM/落地页归因已设计。
- 阻塞：真实询盘投递未业务闭环验证；无 GA4；无 durable webhook；SQL→样品→成交链路在分析侧为**未知**，不得写成 0。
- 动作：受控测试询盘各 1 次、配 GA4（同意后加载）、定义最低可接受指标（有效询盘数、首次响应时间），再加大内容投放。

### 方法 15：外链清单只做候选库 — **已就绪**

- 执行符合方法论：去重、核验、打分、不批量提交。继续按周人工挑 3–5 项。

### 方法 16：按真实受众扩展搜索引擎 — **可小测**

- 现状：IndexNow key 已发布，历史上有成功推送；Bing Webmaster 是否完整接入未在本轮确认；Yandex/Brave 无受众证据。
- 动作：确认 Bing Webmaster + sitemap；IndexNow 在内容更新后重跑；Yandex/Brave 仅在有地区/引荐证据时再加，并分列“提交≠收录≠转化”。

### 方法 17：排名截图先核对 URL — **已就绪（纪律）**

- 继续禁止用第三方域名或 Google 自有结果截图证明本站排名；以 GSC 时间序列为准。

### 方法 18：社区先贡献 — **可小测（高匹配才做）**

- Indie Hackers 对本品类买家匹配度低；更应观察工业采购/五金买家社区。指标用对话与询盘，不用 DR。

### 方法 19：性能以真实用户体验为准 — **可小测（实验室好，现场未知）**

- 实验室分数健康；**无 CrUX / GSC CWV 现场数据**（流量太低常见）。
- 动作：继续修大图与 LCP 资源；有现场数据后再按 LCP/INP/CLS 第 75 百分位排优先级，不为满分砍功能。

## 四、执行优先级对照（方法论三栏 × 本站）

### 直接采用（本站应立刻做）

1. **GSC 查询缺口 + 内容刷新合并 SOP 的“制度”先建起来**——但在样本 ≥50 impressions 前只记录基线，不批量改文。
2. **强化现有比较/替代决策页**（可见更新日期、结论条件、内链、证据位），而不是新开关键词变体。
3. **证据与可引用事实表**（evidence-center / compliance / terms），不用假行业统计。
4. **图片基础优化**：压两张大 JPG、统一优化管线。
5. **30/60/90 天复盘模板**（见第六节）。
6. **转化路径验证**（询盘投递 + GA4 + 响应时间）优先于扩量 SEO。
7. **排名/案例截图核对纪律**。
8. **现场 CWV 就绪后按现场数据排期**；当前用实验室数据只做诊断。

### 小规模测试

1. 社交 SERP：暂缓，除非目标词 SERP 已含社交结果。
2. 高相关 Link Roundup / 展会资料包：继续准备，授权后再提交。
3. 免费选型/RFQ 小工具：中长期，链接合规。
4. AI 辅助聚类改稿：仅在有查询 CSV + 页面正文双输入时。
5. 单一分发渠道：锁定 1 个展会或 1 个经核验目录。
6. 国际 SEO：先补 3 条决策页中文镜像。
7. Bing Webmaster + IndexNow：小规模确认并分列指标。
8. 社区贡献：仅高匹配买家场景。

### 不按原帖 / 明确禁止

- Wikipedia 换链、强制嵌入 dofollow、机械堆关键词、把作者自报数字当因果、Google Sites 寄生页、论坛伪装提问、低价值 Docs/Sites 换链、付费买链、为 DR 发帖。

建议月度只并行 **3–5** 个实验，避免无法归因。
